## Scope and evidence

This audit covers the unavailable values visible in the Dodgers Overview during the current local render and the current 2026 season data path. The evidence combines the Overview JSX, client adapters in `client/src/api/mlb.js`, server proxies, runtime logs, and direct proxy probes. The most important distinction is that the core MLB statistics are working: direct requests for Dodgers team metadata, hitting stats, and pitching stats returned HTTP 200. ## Runtime evidence

The runtime logs contain two distinct MLB failure families. The proxy returned HTTP 503 with `MLB resource temporary upstream cooldown active` for team, affiliate, and schedule calls, and later returned HTTP 504 with `MLB API timed out` for the same kinds of endpoints. These errors explain intermittent MLB auxiliary panels, but they do not explain the FanGraphs model values. The direct MLB team metadata and hitting/pitching probes were successful, which is why the core stat strip is populated.

The direct current FanGraphs probe returned HTTP 502 with `FanGraphs model sources unavailable`. That is the strongest concrete explanation for the unavailable playoff odds, Team WAR, divisional WAR rows, projected wins/losses, and offensive/defensive WAR seen in the current Overview. The cache prevents repeated requests, but it cannot create a verified value when the upstream response is unavailable; it serves a prior verified snapshot only when one exists and remains within the configured stale window.

## Conclusion

The current unavailable values are primarily a **FanGraphs transport/provider availability problem**, not an API-key problem and not a broad MLB data-upload failure. The application is correctly preserving unavailable states instead of substituting guesses. The one area that remains a genuine provider-coverage condition is defensive WAR when FanGraphs omits a verified defensive component from an aggregate response. Ballpark metadata should not be classified as unavailable without a fresh render of that panel, because the current direct MLB response contains the venue.
