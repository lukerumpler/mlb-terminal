# Spacing Reference Notes

Source reviewed: `/home/ubuntu/upload/MLBDashboardProjectVisualExamples.pdf`, pages 1-4.

## Key observations relevant to SKIP Overview and Player Profile

The strongest recurring pattern is a **clear outer rhythm with compact inner density**. Major page sections usually sit in a grid with roughly even gutters, while each panel keeps tighter internal spacing so the layout feels information-rich without turning cluttered.

The team overview examples consistently use a **tighter headline-to-metrics transition** than SKIP currently does. The hero area is compact, but the metric strip directly beneath it feels visually anchored, with limited dead space between the title block, top-line metrics, and the first card row.

The references also show that **panels breathe through consistent padding rather than oversized gaps**. Most cards appear to use moderate internal padding and small but steady inter-card spacing. This creates a more professional front-office density than large vertical separations.

For player-identity surfaces, the useful takeaway is not to make them minimal, but to **group the photo, name, team, and key metadata into one tighter unit**. Supporting controls and secondary context then sit slightly apart, which improves scan order.

Another visible pattern is **alignment discipline**. Related labels, small stat groups, and supporting descriptions align to common edges. This reduces the feeling of uneven spacing even when many data blocks are present.

## Practical direction for this task

For the Team Overview page, favor slightly tighter vertical stacking around the headline, team selector, quick metrics, stat strip, and first panel row. Preserve readability, but reduce any extra empty space between those surfaces.

For the Player Profile page, tighten the hero identity block and the spacing between the hero, confidence strip, tab rail, and the first tab content row. Preserve panel clarity, but make the page feel more deliberate and less loosely stacked.

For both pages, prefer **consistent section rhythm** over dramatic reductions. The goal is to make the screens feel more like a refined baseball operations workspace, not cramped.
