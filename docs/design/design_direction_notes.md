# SKIP design direction from user-provided visual analysis

The target visual direction is a Bloomberg Terminal built with Apple-like restraint. Preserve the product’s baseball intelligence depth, scouting grades, advanced metrics, projections, tables, and visualizations; do not simplify away the competitive advantage. Improve presentation through generous spacing, stronger section separation, a clearer typographic scale, and tiered metric emphasis.

The intended hierarchy is primary metrics first, secondary context next, and tertiary supporting values last. Use accent color selectively for meaningful states and team identity, while keeping small body text readable against neutral surfaces. The player comparison area and radar/geometry visualizations can become signature analytical surfaces, but the interface should remain calm and navigable rather than turning every panel into an equally weighted box.

The recent-history dropdown should support quick backtracking while reinforcing orientation. Breadcrumbs, grouped sections, consistent corner radius, subtle shadows, and whitespace should make the dense player profile feel intentional without removing information.
