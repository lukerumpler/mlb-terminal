# Unavailable Metrics Visual Audit

The current local Overview screenshot shows core MLB team statistics populated: W-L, win percentage, runs, runs allowed, run differential, OPS, home runs, ERA, WHIP, batting average, strikeouts, and stolen bases. The unavailable or non-live items are the FanGraphs playoff-odds value, Team WAR, the divisional WAR chart rows, FanGraphs projected wins, projected losses, offensive WAR, defensive WAR, and the small Team WAR/source badge. Baseball Savant xwOBA and exit velocity are populated and verified.

At the capture time, the FanGraphs source strip reported `not retrieved`, the FanGraphs status badge reported `Loading`, and the page was still connecting for some provider requests. A direct proxy probe returned HTTP 502 for `/api/fangraphs-models?team=LAD&season=2026` with `FanGraphs model sources unavailable`. Direct MLB team metadata and hitting/pitching stats returned HTTP 200, so the core MLB metrics are not blocked by missing API keys. Runtime logs also show MLB Stats API 503 cooldowns and 504 timeouts for schedule, team, and affiliate requests, which explain intermittent non-core MLB panels when those requests fail or are still loading.
